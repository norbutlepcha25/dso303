# Classroom files

Download the files for the instructor-led Cloudboard demonstrations. These examples are separate from the assessed labs.

| Files | Download |
| --- | --- |
| All classroom assets and deployment files | [Download classroom files](downloads/cloudboard-classroom.zip){ download } |
| Website HTML, CSS and release data only | [Download website files](downloads/website-assets.zip){ download } |
| Ready-to-upload CI/CD source archive | [Download pipeline source](downloads/pipeline-source.zip){ download } |

The classroom ZIP contains:

- `website/` — the demo website files.
- `deployment/` — the website policy template.
- `pipeline/` — the pipeline template, buildspec, validation code and source ZIP.

Use these files during the class demonstration. Walkthroughs and practice answers are not included.
